# Kate Golubovich Content Planner

Public application information and privacy policy for a local Windows content planner.

Contact: kate.golubovich123@gmail.com

## Publish using GitHub Pages

Create a public repository, upload the contents of this folder (not the ZIP file),
then choose Settings → Pages → Deploy from a branch → main → /(root) → Save.
Use the address returned by GitHub Pages, and append privacy/ for the privacy policy.

This repository contains only the informational website. It contains no application
credentials, images, publishing queue or account tokens.
