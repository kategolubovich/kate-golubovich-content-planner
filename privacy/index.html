Privacy policy

1. Scope

The application helps its owner prepare, review and schedule original images for her own Pinterest business account. It runs locally on Windows; this website does not operate a publishing backend or receive the application's queue. The distributed desktop build may show the name “Pinterest Publisher”.

The operator does not sell application data or use it for advertising. There is no operator-run account registration system or central database for application users.

2. Information handled

  • Selected content: local file names and paths, prepared copies of images, file hashes used for duplicate checks, titles, descriptions, alternative text, keywords and any destination links entered by the owner.
  • Publishing settings: selected board identifiers and names, time zone, scheduled times, approvals, queue status and identifiers returned for created Pins.
  • Connection information: official Pinterest access and refresh tokens, app credentials where provided, and optional OpenAI API credentials. ChatGPT sign-in may return a verified email address, account subject identifier, OAuth client identifier, granted permissions and session tokens. A stable random installation identifier is used for the ChatGPT connection.
  • API responses and local errors: available boards and models are loaded for selection; local operation logs record errors and publishing outcomes. Errors can include file names and a provider request identifier.

The application does not ask for Pinterest or ChatGPT passwords and does not extract browser session cookies. Authentication and consent take place on the providers' official pages.

3. Why information is used

Information is used to display selected images, generate and edit copy, offer available boards and models, carry out owner-approved publishing, maintain the queue, avoid duplicate uploads, refresh authorized sessions and troubleshoot errors.

Images are sent for AI analysis only when the owner requests and confirms analysis. Pins are sent for publishing only after review and schedule confirmation. Content and account data are not used by the operator to train AI models.

4. External services

OpenAI: when AI analysis is requested, the application sends the prepared selected image and a writing prompt. The prompt may include previously generated local titles to help avoid repetition. Requests use the selected ChatGPT connection or the separately selected API-key mode. The application requests store: false; this is not a promise that OpenAI keeps no operational or safety records. OpenAI handles requests under its own applicable terms, privacy policies and account controls.

Pinterest: official API requests use authorization tokens. Creating a Pin sends its approved image, title, description, alternative text, destination board identifier and optional link. The visibility of created content depends on Pinterest's API access tier and board settings. Pinterest processes authorization and content under its own policies.

No Pinterest API-fetched images, board lists or account data are intentionally included in the OpenAI image-analysis prompt. The owner's selected local image and local title history are the analysis inputs.

These providers may process information outside your country. Their own retention, deletion and account controls apply to their copies of information. See OpenAI's privacy policy and Pinterest's privacy policy.

5. Storage and retention

By default, application files are kept in %LOCALAPPDATA%\PinterestPublisher on the Windows computer. The SQLite database stores the queue, content, settings and logs; an images folder stores prepared copies. Original images are not changed. Queue data and copies remain until the owner removes them; uninstalling or replacing the executable does not automatically erase them.

Credentials and ChatGPT connection profiles are encrypted with Windows DPAPI and bound to the Windows user profile. The application refuses plaintext credential storage if protection fails. The queue database, prepared images and exports are not encrypted by the application; protect the computer and any backups accordingly.

Pinterest board lists and available OpenAI models are loaded into the running interface for selection. Publishing records retain the selected board reference and created Pin identifier to support the approved queue and duplicate checks. Information loaded from a provider is not maintained as a separate general-purpose content archive.

The operator receives no automatic telemetry from the application. If you contact the operator or send an exported archive, screenshot or error report, the operator will receive what you choose to share and use it to answer your request. Do not send passwords or tokens.

6. Your controls and deletion

  • Pause the queue or close the application to stop future publishing from that computer.
  • Use the connection settings to clear saved Pinterest/API credentials. Use the separate ChatGPT sign-out control for the selected ChatGPT connection; it clears local session tokens and attempts remote revocation. If revocation is not confirmed, disconnect the app in ChatGPT settings.
  • Revoke Pinterest or OpenAI authorization using the relevant provider's account controls. Removing credentials locally does not itself guarantee remote revocation.
  • To erase all application data, close the application and remove its data directory, including the queue, image copies and protected credential file. Remove separately created exports and backups if you also want those copies erased.
  • Deleting local files does not delete Pins already created on Pinterest or provider-held records. Manage published Pins and provider data through the relevant service.

For information, correction or deletion requests concerning correspondence received by the operator, contact the address below. The operator cannot remotely access or delete files on your computer. Applicable privacy rights depend on your location and the information involved.

7. This website

This is an informational static website. Its page code contains no analytics, advertising trackers, embedded social feeds, registration form or image uploader. Clicking the contact link opens your email application; sending an email shares your message and sender details with the recipient and email providers.

The hosting and delivery infrastructure may process technical request information, such as IP addresses and browser details, and apply its own security, access or cookie mechanisms. Those infrastructure practices are separate from the local desktop application.
